# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Small sari-sari store owners and operators managing daily inventory, tracking stock levels, monitoring product cost/selling margins, and performing real-time item lookup.

## Product Purpose

Provide a simple, low-friction inventory monitoring system that enables sari-sari store owners to track stock quantities, spot low-stock items before running out, calculate profit margins, and manage inventory movements accurately without complex enterprise overhead.

## Positioning

A lightweight, real-time inventory management dashboard specifically tailored for neighbourhood retail operations, highlighting barcode search, margin visibility, and low-stock alerts.

## Operating Context

Fast-paced retail environment where quick product lookup, cost vs. selling price clarity, barcode scanning, and instant stock level visibility are required during daily sales and restocking workflows.

## Capabilities and Constraints

- **Capabilities**: Barcode & name search, category classification, unit management, cost & selling price tracking, automated margin calculation, low-stock visual indicators, and stock movement logs.
- **Constraints**: Web platform (`web`); Next.js React frontend coupled with Laravel PHP REST API backend over MySQL database inside Docker.

## Brand Commitments

Clean, high-contrast, scanable interface suitable for both desktop dashboards and handheld mobile browsers in store environments.

## Evidence on Hand

- Standard sari-sari store product catalog pre-seeded in MySQL database (e.g., Lucky Me!, Kopiko, Bear Brand, 555 Sardines).
- Active Next.js frontend on port 3001 and Laravel API on port 8000.

## Product Principles

1. **Scannability First**: Critical information (stock count, margin, low-stock warnings) must be clear at a single glance.
2. **Zero-Friction Operations**: Searching by name or barcode must return instantaneous results.
3. **Data Integrity**: Financial margins and stock movements must be strictly calculated and accurately represented.
4. **Responsive Adaptability**: Full operational utility on mobile screens used on the shop floor as well as desktop monitors.

## Accessibility & Inclusion

High contrast text ratios, clear semantic HTML elements, and keyboard-navigable search and input fields for effortless visibility in varied lighting conditions.
